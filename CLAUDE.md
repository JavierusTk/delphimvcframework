## Overview

**DelphiMVCFramework** is the most popular Delphi RESTful framework on GitHub. It provides a complete MVC architecture for building RESTful services, JSON-RPC APIs, and web applications with Object Pascal.

- **Current stable version**: 3.4.2-magnesium
- **Supported Delphi versions**: Delphi 10.0 Seattle through Delphi 13 Florence
- **License**: Apache 2.0

## Building and Installation

### Package Structure

Packages are organized by Delphi version in `packages/d{version}/`:
- `dmvcframeworkRT.dpk` - Runtime package
- `dmvcframeworkDT.dpk` - Design-time package (requires RT installed first)
- `loggerproRT.dpk` - LoggerPro logging framework
- `SwagDoc.dpk` - Swagger documentation generator

### Build Commands

```bash
# Open the package group for your Delphi version (e.g., Delphi 12)
packages/d120/dmvcframework_group.groupproj

# Build order:
1. loggerproRT.dpk
2. SwagDoc.dpk
3. dmvcframeworkRT.dpk
4. dmvcframeworkDT.dpk (Install this one)
```

### Required Library Paths

Add to RAD Studio library path:
- `sources/`
- `lib/loggerpro/`
- `lib/swagdoc/Source/`
- `lib/dmustache/`

## Running Tests

```bash
# Open the test group project
unittests/general/DMVCFrameworkTestsGroup.groupproj

# Run order:
1. Start TestServer.dpr (server must be running)
2. Run DMVCFrameworkTests.dpr (console) or DMVCFrameworkGUITests.dpr (GUI)
```

Tests require the test server running on port 8080.

## Architecture

### Core Components

| Unit | Purpose |
|------|---------|
| `MVCFramework.pas` | Main engine (`TMVCEngine`), base controller (`TMVCController`), attributes |
| `MVCFramework.Router.pas` | URL routing and controller dispatch |
| `MVCFramework.Commons.pas` | Constants (`TMVCMediaType`), HTTP types, shared utilities |
| `MVCFramework.Container.pas` | Dependency injection container |

### Subsystem Organization

- **ActiveRecord ORM**: `MVCFramework.ActiveRecord*.pas`, `MVCFramework.SQLGenerators.*.pas`
- **Serialization**: `MVCFramework.Serializer.*.pas` (JSON, HTML, Text, URLEncoded)
- **Middleware**: `MVCFramework.Middleware.*.pas` (JWT, CORS, Compression, StaticFiles, etc.)
- **REST Client**: `MVCFramework.RESTClient*.pas`
- **JSON-RPC**: `MVCFramework.JSONRPC*.pas`
- **WebSockets/SSE**: `MVCFramework.WebSocket.*.pas`, `MVCFramework.SSE*.pas`
- **View Engines**: `MVCFramework.View.Renderers.*.pas` (Mustache, TemplatePro, WebStencils)
- **RQL Parsers**: `MVCFramework.RQL.AST2*.pas` (per database)

### Database Support

MVCActiveRecord supports via SQL generators in `sources/`:
- PostgreSQL, MySQL/MariaDB, SQLite, Firebird, InterBase, MS SQL Server

RQL (Resource Query Language) translators in `MVCFramework.RQL.AST2{DB}SQL.pas`.

### Compiler Directives

`sources/dmvcframework.inc` defines version symbols:
- `SEATTLEORBETTER`, `BERLINORBETTER`, `TOKYOORBETTER`, `RIOORBETTER`
- `SYDNEYORBETTER`, `ALEXANDRIAORBETTER`, `ATHENSORBETTER`, `FLORENCEORBETTER`
- `CUSTOM_MANAGED_RECORDS` (Sydney+)
- `WEBSTENCILS` (Athens+)

All framework units require `{$I dmvcframework.inc}`.

## Key Patterns

### Controller Definition

```pascal
[MVCPath('/api/customers')]
TCustomerController = class(TMVCController)
public
  [MVCPath]
  [MVCHTTPMethod([httpGET])]
  function GetCustomers: TObjectList<TCustomer>;

  [MVCPath('/($id)')]
  [MVCHTTPMethod([httpGET])]
  function GetCustomer(id: Integer): TCustomer;
end;
```

### Engine Setup (WebModule)

```pascal
procedure TWebModule1.WebModuleCreate(Sender: TObject);
begin
  FMVC := TMVCEngine.Create(Self,
    procedure(Config: TMVCConfig)
    begin
      Config[TMVCConfigKey.ViewPath] := '.\templates';
    end);
  FMVC.AddMiddleware(TMVCCORSMiddleware.Create);
  FMVC.AddController(TCustomerController);
end;
```

### ActiveRecord Entity

```pascal
[MVCTable('customers')]
TCustomer = class(TMVCActiveRecord)
private
  [MVCTableField('id', [foPrimaryKey, foAutoGenerated])]
  fID: Integer;
  [MVCTableField('name')]
  fName: string;
public
  property ID: Integer read fID write fID;
  property Name: string read fName write fName;
end;
```

### Middleware Pattern

```pascal
type
  TMyMiddleware = class(TInterfacedObject, IMVCMiddleware)
    procedure OnBeforeRouting(Context: TWebContext; var Handled: Boolean);
    procedure OnBeforeControllerAction(Context: TWebContext; const AControllerQualifiedClassName: string; const AActionName: string; var Handled: Boolean);
    procedure OnAfterControllerAction(Context: TWebContext; const AControllerQualifiedClassName: string; const AActionName: string; const AHandled: Boolean);
    procedure OnAfterRouting(Context: TWebContext; const AHandled: Boolean);
  end;
```

## Samples Reference

Samples in `samples/` are categorized by feature:
- **Core REST**: `basicdemo_server`, `routing`, `renders`, `functional_actions_showcase`
- **Auth**: `jsonwebtoken*`, `custom_auth`, `custom_role_auth`
- **Middleware**: `middleware_*` (cors, compression, etag, ratelimit, staticfiles)

- **Views**: `serversideviews_*`, `htmx*`
- **Real-time**: `websocket_*`, `serversentevents*`
- **Deployment**: `ISAPI/`, `apache_module/`, `windows_service`

Most samples run on port 8080 by default.

- **JSON library**: Uses `JsonDataObjects.pas` (not System.JSON)
- **Database layer**: FireDAC required for ActiveRecord
- **Default port**: Most samples use 8080
- **IDE Wizard**: After installing DT package, use File → New → Other → DMVC
